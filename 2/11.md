# DV아/어/여지다, AV게 되다 to become <a name="1"></a>

In Korean grammar, `DV -아/어/여지다` and `AV -게 되다` are both used to describe changes of state

- `DV아/어/여지다` “to become ~ / to get ~”
- `AV게 되다` “to come to / end up / happen to”.

Note: 되었어요 (written) = 됐어요 (spoken).
